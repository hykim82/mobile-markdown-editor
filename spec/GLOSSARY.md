# 명칭 사전

**이 명칭만 사용한다. 동의어·재작명 금지. 한 개념 = 한 이름.**

## 화면
- **메모 목록(홈)** — 저장된 메모를 최신 수정순으로 보여주는 홈 화면. 단일 깊이.
- **에디터** — 마크다운을 입력·편집하는 화면.

## 기능
- **마크다운 입력** — 에디터에서 마크다운 원문을 그대로 입력하는 기능.
- **미리보기** — 마크다운을 렌더링해 보여주는 토글. 기본 OFF.
- **단축키바(자음더블)** — 자판 위 엄지존에 뜨는 마크다운 삽입 칩 바.
- **노션 복사** — 본문 마크다운 평문을 클립보드에 복사하는 기능.
- **삭제(+되돌리기)** — 목록 스와이프로 지우고 7초간 되돌릴 수 있는 기능.
- **실행취소** — 플랫폼 관습 실행취소.

## 데이터 필드 (메모)
- **id** — UUID, 필수, 자동 생성.
- **제목** — 문자열, 기본값은 본문 첫 줄에서 자동 갱신.
- **본문** — 문자열, 마크다운 원문, 필수, 빈 값은 저장 안 함, 길이 무제한.
- **생성시각** — 첫 글자 입력 순간의 시각.
- **수정시각** — 저장할 때마다 갱신, 정렬 키.
- **삭제시각** — 기본 null, soft delete 표시, 7초 뒤 hard delete, 되돌리기 시 null 복원.

## 자음더블 매핑 (⚠빌드 전 사용자 최종 확정 필요)
- **ㅎㅎ → #** — 제목.
- **ㅁㅁ → -** — 목록.
- **ㅂㅂ → \*\* \*\*** — 굵게, 커서 가운데.
- **ㅈㅈ → - [ ]** — 체크박스.
- **ㅅㅅ → ~~ ~~** — 취소선.

## 정책 이름
- **생성** — 첫 글자 입력 순간 메모 생성(빈 메모 미저장).
- **자동저장** — 1초 디바운스, 화면 이탈·백그라운드·미리보기 토글 시 즉시 저장.
- **soft delete** — 삭제시각 표시로 목록에서 숨김(7초 유예).
- **hard delete** — 7초 뒤 실제 영구 삭제(휴지통 없음).
- **보존** — 무제한 로컬 보존, 앱 삭제 시 전 메모 소실(최초 1회 고지).
- **자동저장 실패** — 1회 재시도 → 메모리 유지, 입력마다 재시도, '저장됨' 미표시.
- **조합 깨짐(commit 후 삽입)** — 한글 조합 확정 후 삽입, 실패 시 본문 불변.
- **서식 깨짐(평문 그대로 복사)** — 변환·가공 없이 마크다운 평문 그대로 복사.

## 토큰 이름 (값은 /spec/design-tokens.json)
- **color.accent** — 강조 1색(캐럿·복사 버튼). **color.accent.hover** — 복사 버튼 hover.
- **color.focus.ring** — 포커스 링(2px). **color.disabled** — 비활성(빈 본문 복사 버튼).
- **color.bg** / **color.bg.elevated** — 배경 / 떠 있는 면(칩·카드).
- **color.text.primary** / **color.text.muted** — 본문 / 보조 텍스트. **color.border** — 경계선.
- **color.state.error** / **color.state.success** — 오류 / 성공.
- **motion.duration.base** — 200ms(미리보기 페이드·토스트). **motion.duration.fast** — 120ms.
- **font.size.body** — 17px(본문). **line.height.body** — 1.6.

## 마이크로카피 (고정 문구)
- 에디터 빈 상태 — "오늘 뭐 적어볼까요?"
- 입력 중 저장 표시 — "저장됨"
- 복사 완료 토스트 — "노션에 복사됐어요 ✓" (2초)
- 복사 오류 — "복사가 안 됐어요. 다시" (+재시도)
- 목록 빈 상태 — "아직 메모가 없어요. +로 시작"
- 목록 오류 — "불러오기 실패 · 다시"
- 최초 실행 고지 — "메모는 이 기기에만 저장됩니다"
