# PRD — 한 손 마크다운 에디터

## 1. 개요
- **문제 한 줄**: 이동 중 한 손으로 폰을 쥐고 노션에 일감을 적을 때, 마크다운 기호 입력이 번거롭고 한글 조합이 자주 깨진다.
- **JTBD**: When 이동 중 한 손으로 떠오른 일감을 적을 때, I want to 마크다운을 빠르고 안 깨지게 입력해, So I can 노션에 그대로 깔끔히 옮긴다.
- **솔루션 한 줄**: 한 손 모바일 마크다운 에디터 + 노션 복사.
- **톤**: 차분·미니멀·또박또박·한 손·거슬림 없는.

## 2. 목표·성공지표·LOFA/가정
- **성공·검증 지표**(고객=나, 출시 후 검증):
  1. 주간 재사용(잔존) — 주 단위로 앱을 다시 열어 새 메모를 만드는 주가 이어지는지.
  2. 세션당 '노션 복사' 횟수 — 한 번 열었을 때 '노션 복사'가 실제 실행되는지(완료 토스트 도달).
  3. 입력 취소·재입력 빈도 감소 — 실행취소·지우고 다시 치는 횟수가 줄어드는지(감정 최저점=재입력 감소).
- **LOFA**: 전용 에디터가 노션 직접 입력보다 덜 번거로워서 이동 중 이걸 연다(행동 변화) — 아니면 그냥 노션 앱 사용.

## 3. 범위·제약
- **MVP(in)**: 마크다운 입력 · 미리보기 · 단축키바(자음더블) · 노션 복사 · 삭제(+되돌리기) · 실행취소.
- **백로그(out)**: 위젯 · 공유시트 빠른 캡처 · 검색 · 클라우드 동기화 · 스니펫 · 테마 수동 토글 · 표시 설정(글자/줄간격/폰트) · 내보내기 · 이미지 첨부 · 설정 화면.
- **비목표**: 서버 운영·원격 DB·다기기 동기화·서버 푸시·외부 API 없음.
- **제약**: 로컬·클립보드 우선(서버 없음) · 개인 프로젝트 기간·토큰 한정.
- **타깃 플랫폼**: 모바일 중심 · 홈중심(단일 깊이). **테마**: 둘 다 + 시스템 자동(OS 변경 시 즉시 반영).

## 4. 사용자·시나리오
- **Actor**: 나(40대 운영팀장, 이동 중 한 손).
- **시나리오**: 지하철·밤 이동 중 떠오른 일감을 폰으로 빠르게 마크다운 메모하고, 노션에 그대로 옮겨지길 기대. 터지는 상황 — ① 퇴근 지하철(서서·한 손) ② 밤, 아이 재운 뒤 침대 ③ 외근 이동 중.
- **CUJ 진입**: 이동 중 일감이 떠올라 앱을 연다. **종료**: 노션에 마크다운 그대로 붙어 정리됨.
- **CUJ 6스텝**: ①앱 열기(바로 새 메모) ②마크다운 입력(단축키바 — 감정 최저점: 조합 깨져 재입력) ③미리보기(200ms 페이드) ④자동저장('저장됨') ⑤노션 복사(토스트+햅틱) ⑥붙여넣기 Aha(서식 깨짐=신뢰 붕괴 리스크).

## 5. 기능 명세

### 5.1 마크다운 입력
- 화면: 에디터. 본문 17px·1.6·캐럿 color.accent. 빈 상태 "오늘 뭐 적어볼까요?". 커서·선택 핸들·길게 눌러 선택·전체 선택 기본 제공.
- 수용 기준: ①첫 글자 입력 시 메모 생성·저장(빈 메모는 목록에 안 생김) ②마크다운 원문 그대로 저장·길이 무제한 ③백그라운드 전환 시 즉시 저장 ④커서/선택 핸들/전체 선택 동작.

### 5.2 미리보기
- 화면: 에디터(토글). 200ms 페이드(motion.duration.base). 토글 시 즉시 저장. **기본 OFF(입력 우선)**.
- 수용 기준: ①토글 200ms 페이드 전환 ②토글 순간 즉시 저장 ③초장문에도 입력·저장 안 막힘(미리보기 지연만 허용).

### 5.3 단축키바(자음더블)
- 화면: 에디터, 자판 위 엄지존. 칩 bg.elevated·눌림 명도↓·≥44px.
- 매핑(임시 확정 · ⚠빌드 전 사용자 최종 확정 필요): ㅎㅎ→`#`(제목) / ㅁㅁ→`-`(목록) / ㅂㅂ→`** **`(굵게, 커서 가운데) / ㅈㅈ→`- [ ]`(체크박스) / ㅅㅅ→`~~ ~~`(취소선).
- 수용 기준: ①칩 탭→커서 위치 즉시 삽입 ②조합 확정(commit) 후 삽입 — 한글 조합 안 깨짐 ③삽입 실패 시 본문 불변 ④≥44px·자판 위 엄지존.

### 5.4 노션 복사
- 화면: 에디터('노션 복사' 버튼, 복사 후 에디터 유지). 1탭+가벼운 햅틱. 완료="노션에 복사됐어요 ✓"(하단 토스트 2초) / 오류="복사가 안 됐어요. 다시"+재시도. **빈 본문일 때 color.disabled 비활성**.
- 수용 기준: ①1탭으로 클립보드에 마크다운 평문 그대로(변환·가공 없음) ②성공 토스트 2초+햅틱 ③복사 후 에디터 유지 ④실패 시 재시도 표시·원문 로컬 보존.

### 5.5 삭제(+되돌리기)
- 화면: 메모 목록(스와이프).
- 수용 기준: ①스와이프 시 목록에서 숨김+되돌리기 토스트 ②되돌리기 누르면 복원 ③7초 경과 시 hard delete ④별도 확인 단계 없음.

### 5.6 실행취소
- 화면: 에디터. 플랫폼 관습 기본 제공.
- 수용 기준: ①플랫폼 관습 방식으로 동작 ②방금 입력/삽입을 되돌림.

## 5b. NFR 모음(위험한 것만)
- **성능**: 실행→입력 1초 내(입력이 목록 로딩 안 기다림) / 전환 ≤200ms / 자동저장 1초 디바운스 / 초장문 입력·저장 차단 X.
- **접근성**: 터치 ≥44px(엄지존) / 본문 ≥17pt·1.6 / focus.ring 2px.
- **프라이버시**: 요구 권한 없음 / 전부 기기 로컬 / 수집 0 / 최초 실행 1회 고지 "메모는 이 기기에만 저장됩니다" / 앱 삭제=전 메모 소실.

## 8. 정책
| 구분 | 규칙 |
|---|---|
| 생성 | 첫 글자 입력 순간 생성·저장(빈 메모 저장 안 함) |
| 자동저장 | 입력 멈춤 1초 디바운스 + 뒤로가기·백그라운드 전환·미리보기 토글 시 즉시 저장 |
| 삭제 | 스와이프 soft delete + 되돌리기 토스트 7초 후 hard delete(휴지통 없음), 확인 단계 없음 |
| 보존 | 자동 만료·개수 제한 없음. 앱 삭제=전 메모 소실(최초 실행 1회 조용한 고지) |
| 자동저장 실패 | 즉시 1회 재시도→메모리 유지·입력마다 재시도. 에디터 벗어나기 전 내용 절대 안 버림. '저장됨' 미표시로 알림 |
| 저장공간 부족 | 위와 동일 + 캐시 정리 시도, 알림 O |
| 노션 복사 실패 | "다시" 재시도(클립보드 재쓰기), 원문 로컬 보존 |
| 서식 깨짐 | 클립보드에 마크다운 평문 그대로(변환·가공 없음) |
| 한글 조합 깨짐 | 단축키바 삽입은 조합 확정(commit) 후 커서 위치 삽입, 실패 시 본문 불변 |
| 목록 불러오기 실패 | 재시도, 저장 파일 훼손 없음(읽기 전용 실패) |
| 진입 | 실행→입력 1초 내, 입력이 목록 로딩 안 기다림 |
| 엣지 | 초장문 무제한(미리보기 지연 허용) / 중단=백그라운드 즉시 저장이 방어선 / 오프라인=전 기능 무관 / 권한 거부=해당 없음(클립보드 무권한) |
